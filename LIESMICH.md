# Hydro-Assistent v1

Nährlösungs-Rechner für 3 DWC-Eimer: Neu ansetzen, TOP-UP, Mischanleitung, Verlauf, Pflanzendoktor, Erntekalender.

Alle Daten bleiben auf dem Handy (im Browser gespeichert). Nichts wird an einen Server geschickt.
Sicherung: Einstellungen → „Sicherung speichern“ / „Sicherung laden“.

Neue Fassung einspielen: `index.html` ersetzen und in `sw.js` die Versionsnummer erhöhen.
